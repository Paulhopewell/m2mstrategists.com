# paulhopewell.com

Static site for Paul Hopewell LLC — AI, Growth & Exit Strategy.

Built and maintained by the 7-agent OpenClaw website team (Chairman-approved, 1 June 2026).

## Architecture

- **Hosting:** Netlify (auto-deploy from `main` branch)
- **Framework:** Static HTML/CSS
- **DNS:** EasySpace (pending cutover to Netlify)
- **Agents:** Content, Design Direction, SEO/Performance, Deployment, Analytics, Security, Orchestrator

## Local Development

```bash
python3 -m http.server 8888
```

Open http://localhost:8888

## Deploy

Push to `main`. Netlify auto-deploys.
